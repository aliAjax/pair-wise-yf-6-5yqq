# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版：报价锁定与验收闭环

- 每个未完成事项可维护多条候选报价，选定一条后事项转为处理中并锁定；施工方、承诺费用、上门日期、保修天数缺一即整次拒绝，原报价和状态不变。
- 完工验收须填实付费用和验收结论；实付超过承诺费用时还须填超支原因，缺项则保持原状态。验收退回须记整改说明，事项继续处理中。
- 终止报价须填原因，终止后释放当前报价（事项回到待处理，可重新选定），历史报价保留可查。
- 头部统计（未完成、处理中、待支付费用、已实付费用）随每次变更写入 localStorage，与本地数据保持同步。
