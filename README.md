## 报价锁定与验收闭环

数据保存在浏览器 localStorage（key：`zfl-14-repairs`），所有状态与费用统计均从本地数据实时计算。

1. **候选报价**：未完成事项（待处理/处理中且未锁定）可以添加多条候选报价，施工方、承诺费用、上门日期、保修天数四项缺一即整次拒绝，已有报价和事项状态不变。
2. **选定锁定**：每条完整候选报价可“选定”；选定后事项转为“处理中”，该报价锁定，不能再增选报价，只能走完工验收或终止。
3. **完工验收**：
   - 实付费用、验收结论必填，缺项则提交作废、保持“处理中”；
   - 实付超过承诺费用时必须填写超支原因；
   - 验收通过：事项转为“已完成”；
   - 验收退回：必须填写整改说明，记录后继续“处理中”，锁定报价保持不变。
4. **终止**：处理中的事项可终止，必须填写终止原因；终止后释放当前锁定报价（报价不删除，标记为“已释放”），事项转为“已终止”，全部报价与处理历史保留可查。
5. **费用统计**：未完成数、处理中数、未完成事项锁定报价的承诺费用合计、完工实付合计与超支合计，随本地数据实时同步。
6. 已完成/已终止事项只读，报价记录与处理历史（锁定、通过、退回、终止）持续保留。
